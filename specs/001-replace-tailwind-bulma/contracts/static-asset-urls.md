# Contract — Static asset URL map

**Feature**: `001-replace-tailwind-bulma`

This contract defines the stable URLs the application serves for
embedded static assets. Templates, handlers, and the validation
procedure all depend on these URLs.

## URL prefix

All embedded assets are served under `/static/` by
`internal/assets.NewStaticFileServer()`. The prefix MUST NOT change.

## Required URLs

| URL | Source path (in repo) | Notes |
|---|---|---|
| `/static/css/bulma.min.css` | `internal/server/static/css/bulma.min.css` | Vendored Bulma 0.9.4 |
| `/static/css/app.css` | `internal/server/static/css/app.css` | RunRun overrides (small, hand-written) |
| `/static/js/vendor/alpine.csp.min.js` | `internal/server/static/js/vendor/alpine.csp.min.js` | Alpine.js v3 CSP build |
| `/static/js/main.js` | `internal/server/static/js/main.js` | LogStream + delegated event handlers |
| `/static/js/log-viewer.js` | `internal/server/static/js/log-viewer.js` | ANSI rendering helper |
| `/static/icons/sprite.svg` | `internal/server/static/icons/sprite.svg` | SVG sprite, glyphs referenced via `<use href="…#id">` |
| `/static/favicon.ico` | `internal/server/static/favicon.ico` | Unchanged |

## Forbidden URLs (MUST 404 after migration)

| URL | Reason |
|---|---|
| `/static/css/styles.css` | Tailwind output — file removed |
| `/static/css/input.css` | Tailwind source — file removed |
| `/static/css/style.css` | Stray legacy file — removed |

## Cache headers

Every response under `/static/` MUST set:

```http
Cache-Control: public, max-age=31536000, immutable
ETag: "<content-hash>"
```

URLs emitted by `base.templ` MUST include a `?v=<short-git-sha>`
query string for cache busting on deploy.

## Headers that MUST be present on every HTTP response

(Not asset-specific, but contract for the whole feature.)

```http
Content-Security-Policy: default-src 'self';
  script-src 'self' 'nonce-{NONCE}';
  style-src 'self';
  img-src 'self' data:;
  font-src 'self';
  connect-src 'self';
  frame-ancestors 'none';
  base-uri 'self';
  form-action 'self';
  object-src 'none'
```

Where `{NONCE}` is a fresh, request-scoped value (≥128 bits of
entropy) generated by `CSPNonceMiddleware`.

## Acceptance tests (Go-side)

- `internal/assets/embed_test.go` MUST assert that each required URL
  resolves to a non-empty body and the documented `Content-Type`.
- A new test MUST assert that each forbidden URL returns `404`.
- A new middleware test MUST assert:
  - The CSP header is present on `/login` and `/dashboard`.
  - The header contains a unique `nonce-…` per request.
  - The header does not contain `'unsafe-inline'` or
    `'unsafe-eval'`.
